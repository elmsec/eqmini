# eqMini 0.4.0 — preview 5

The first normal launch now opens the equalizer window. Closing it keeps eqMini running in the menu bar.

Later startups stay in the menu bar, including launch at login. Login launches do not consume the one-time welcome window. Click the tray icon for the popup, or choose Open Equalizer for the full window.

Requires **Apple silicon** and **macOS 14.2+**. Quit eqMini before replacing it in Applications.

The app and DMG are Developer ID signed and notarized by Apple. ZIP and SHA-256 checksums are included.

Build 9. [Usage and source](https://github.com/elmsec/eqmini/blob/v0.4.0-preview.5/README.md).
