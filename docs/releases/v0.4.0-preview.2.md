# eqmini 0.4.0 — preview 2

This preview adds Developer ID signing and Apple notarization. Audio processing and controls are unchanged.

Requires **Apple silicon** and **macOS 14.2+**. Download the DMG, drag eqmini into Applications, and open it. The ZIP contains the same app. Both packages have stapled notarization tickets and pass local Gatekeeper assessment. SHA-256 checksums are included.

System Audio Recording permission is still required for live EQ. eqmini explains this before requesting access. It does not save recordings or make network requests.

Build 6. See the [README](https://github.com/elmsec/eqmini/blob/v0.4.0-preview.2/README.md) for usage and known limits.
