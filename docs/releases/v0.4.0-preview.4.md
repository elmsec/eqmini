# eqMini 0.4.0 — preview 4

- Consistent eqMini name and three-fader icon throughout the app.
- Normal launches open the menu-bar panel. Login launches stay quiet.
- Clear Enable/Disable labels.
- A reminder in the regular window explains that closing it keeps eqMini running.

Requires **Apple silicon** and **macOS 14.2+**. Quit the previous copy, then move **eqMini.app** from the DMG into Applications. If Finder keeps the older lowercase-named copy, remove that duplicate to avoid opening the wrong version. Your saved settings use the same bundle identity.

The app and DMG are Developer ID signed and notarized by Apple. System Audio Recording permission is required for live EQ. ZIP and SHA-256 checksums are included.

Build 8. [Usage and source](https://github.com/elmsec/eqmini/blob/v0.4.0-preview.4/README.md).
